# Published email addresses

IDEAS publishes no contact email addresses or `mailto:` links. The production
assertions scan every file in `_site`, including HTML, JavaScript, JSON, XML,
SVG, CSS and binary image metadata such as EXIF, IPTC and XMP.

There is one upstream attribution exception, recorded in
[issue #13](https://github.com/mvictoras/www-ideas/issues/13), which clarifies the
no-email acceptance criterion in issue #2. The search dependency
`assets/al_search/js/search/hotkeys-js/hotkeys.esm.min.js` retains the exact
copyright line `Copyright (c) 2024 kenny wong <wowohoo@qq.com>` in its license
comment. The assertion exempts only that line in that file; other addresses
and all `mailto:` links still fail. The published dependency is not modified.

Keep upstream license notices intact. If a dependency upgrade changes this
notice, review the new attribution before changing the exception.
